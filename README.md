# Midnight Portfolio — Shahd Atya

A responsive personal portfolio made with HTML, CSS, and Bootstrap 5.

## Files
- `index.html` — the website structure and content
- `style.css` — colors, layout, typography, and responsive styling

## How to run it
1. Download or extract the project folder.
2. Open `index.html` in a browser.
3. An internet connection is needed to load Bootstrap and Google Fonts from their CDNs.

## Before submitting
- Replace `your.email@example.com` with your real public contact email, or remove the email link.
- Replace the GitHub and LinkedIn profile links with your own links.
- Edit the About section so it accurately describes you.
- Keep the Task Planner and Study Dashboard marked as concepts until you actually build them.
- Test the page on both mobile and desktop.
- Upload both `index.html` and `style.css` to your GitHub repository.

## Publish with GitHub Pages
1. Create a GitHub account if you do not have one.
2. Create a new public repository named `portfolio`.
3. Upload `index.html`, `style.css`, and this README.
4. Open the repository's **Settings → Pages**.
5. Under the build/deployment section, select **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then save.
7. Wait a little and refresh the Pages section. GitHub will show the published website URL.

## Important
The social links and contact email are placeholders. Update them before publishing. The portfolio is a starter project for learning; make sure you understand the code and can explain the main sections during your practical assessment.
